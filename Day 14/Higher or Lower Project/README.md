# Higher Lower Game

A simple Python command-line game where the player guesses which person, brand, or celebrity has more social media followers.

## How to Play

1. Two accounts are displayed: **A** and **B**.
2. Each account shows its name, description, and country.
3. Enter **A** or **B** to guess which account has more followers.
4. If your guess is correct, your score increases and the game continues.
5. If your guess is incorrect, the game ends and your final score is displayed.

## Features

* Random account selection from a dataset
* Score tracking
* Continuous gameplay until an incorrect guess
* Simple command-line interface
* ASCII art logo and comparison screen

## Requirements

* Python 3.x

## Project Files

* `main.py` – Main game logic
* `game_data.py` – Contains account data and follower counts
* `art.py` – Contains ASCII art used in the game

## How to Run

1. Clone or download the project.
2. Open a terminal in the project directory.
3. Run the game:

```bash
python main.py
```
